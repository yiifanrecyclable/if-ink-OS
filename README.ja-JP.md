# if-ink OS

**v0.1.6** — MindReset Read Pico RDP-G01-W 向けの独立ファームウェアです。

[インストールとダウンロード](https://yiifanrecyclable.github.io/if-ink-OS/) · [Release](https://github.com/yiifanrecyclable/if-ink-OS/releases/tag/v0.1.6) · [English](README.md) · [简体中文](README.zh-CN.md)

- EPUB・TXT・Markdown のオフライン読書。Markdown の表、見出し別サイズ、太字、斜体、ハイライトに対応。
- Nutstore WebDAV の一覧から MD・TXT・EPUB を選択し、TFカードへ保存。
- 日付と格言、読書記録、最近の読書、統一したシステム文字設定。
- 読書パネル、目次、しおり、選択式ジェスチャー、WiFiパスワード保存、中国語/英語のシステム表示、オンライン更新。

初回はパソコンのChrome/Edgeでオンラインインストールできます。既存のIF/if-ink OSにはTF更新パッケージも利用できます。固定ディレクトリは `books`、`fonts`、`markdown` です。Obsidianプラグインと個人アカウント設定は含みません。

0.1.6は完全ビルドとホスト回帰チェックを通過しています。新しい Banner、壁紙スライドショー、実際の画面更新効果は実機検証が必要です。

[Pico Reader rc83](https://github.com/wegooo-cell/read-pico-reader)を基に、後続rc88/rc95の一部改善を採用しています。[原作者のページ](https://wegooo-cell.github.io/read-pico-reader/)に感謝します。原作者またはMindResetの公式リリースではありません。
