# if-ink OS

**稳定版 v0.1.7 · 测试版 v0.2.0-beta** · 支持 Markdown 文档的 Pico 固件。仅适用 MindReset Read Pico RDP-G01-W。

[在线刷机与下载](https://yiifanrecyclable.github.io/if-ink-OS/) · [版本与离线包](https://github.com/yiifanrecyclable/if-ink-OS/releases/tag/v0.1.7) · [安装说明](docs/安装说明.md) · [构建与重新链接](BUILDING.md)

- EPUB、TXT、Markdown 离线阅读，支持图片与文字混排、表格、标题字号、粗体、斜体与高亮。
- 坚果云 WebDAV 获取文件列表，按需下载 MD/TXT/EPUB，保存到 TF 卡。
- 自定义 Banner 首页、每日阅读打卡与目标设定、壁纸轮播、最近阅读，以及统一字号、字体和分割线界面。
- 阅读控制面板、书签、目录、可选快捷手势、WiFi 密码记忆、中文/English系统界面及独立在线升级。
- WiFi／热点网页可编辑 Banner 与锁屏、预览实际设备排版、同步电脑TTF字体并管理TF文件。

首次安装用电脑 Chrome/Edge 打开在线刷机页；已有 IF/if-ink OS 的设备可使用 TF 升级包。在线安装不需要 Python。离线 USB 包包含固件及刷写参数，手动刷写需提前准备 Python 和 esptool。TF 卡固定目录为 `books`、`fonts`、`markdown`；首次可下载字体与拼音词库资源包。含更新器的版本可在“设置 → 固件信息 → 在线升级”检查后续版本。同版本无需重复安装。0.1.7已通过完整构建与宿主检查，本版新增功能的最终墨水屏与休眠效果仍需真机验证。

Obsidian 推送插件为独立项目，本固件发布包不包含插件及任何账号配置。坚果云的应用密码在设备设置中手动填写。

基于 [Pico Reader 0.3.3-rc83](https://github.com/wegooo-cell/read-pico-reader)，选择性采用后续 rc88/rc95 的阅读、刷新与存储改进；保留 if-ink OS 的界面与刷新策略。感谢[原作者主页](https://wegooo-cell.github.io/read-pico-reader/)。本项目是独立衍生版本，不是原作者或 MindReset 官方发布。

### 阅读进度存储

TF卡可用时，续读位置、阅读百分比和最近阅读顺序保存到卡内的隐藏目录 `.readpico/progress`。请保留该目录；转移整张卡或备份时一并复制。每项记录使用CRC校验双副本，保存时同步并读回校验；写入失败不会显示为保存成功。旧NVS记录继续可读，之后的阅读更新保存到TF，无卡时旧NVS仅供读取，保存内容记录需插入TF卡。设置中的“保存与恢复”包含新进度库，兼容旧备份。旧版尚未成功保存、并已随重启丢失的内存进度无法恢复。

### 内容记录与系统设置

系统设置和账号凭据继续保存在设备内部NVS；随书籍增长的书签、书名覆盖、置顶、移出书架、逐书提示及阅读统计保存到TF的 `.readpico/records`，逐本进度仍使用 `.readpico/progress`。请保留并随卡备份这两个隐藏目录。

卡就绪且无阅读或传输占用时，固件会迁移可识别的旧NVS内容记录：先保存可校验的恢复副本，再核对TF记录，最后逐键清退旧内容以释放设置空间。已有TF数据和删除标记优先；损坏、未知记录和账号凭据不会被自动清除。无卡时内容写入会返回失败，不会重新挤占NVS。若未知数据仍占满NVS，设置保存仍可能失败，诊断目录保留占用清单和迁移结果。恢复不保证旧固件能直接读取新内容库；降级前应另行备份。

### 图片文件浏览

长按文件或文件夹会从底部导航栏上方展开文件操作卡片，提供重命名、复制、移动和删除；点击右上角关闭或卡片外空白处收起。JPG/JPEG/PNG的宽高比与684×1216相差不超过5%时，卡片还提供“设为息屏壁纸”，成功保存后会替换原来的固定或轮播壁纸。文件操作结果临时显示在顶部中央，约4秒后恢复状态栏。

存储卡管理中的`pictures`和`banner pic`及其子目录可在标题右侧切换列表/缩略图；单击查看图片，再点图片任意位置返回原目录，保留原分页和显示模式；长按管理。图片网格最多九项，Banner宽幅网格最多八项，按页显示；模式在本次开机中分别沿用。缩略图支持JPG/JPEG/PNG，首访生成并在`.readpico/thumbnails`缓存；无法解码时保留占位及文件操作。此缓存可单独删除重建，不要删除包含阅读记录的整个`.readpico`目录。五个固定根目录books、markdown、fonts、pictures、banner pic不能改名、复制、移动或删除，内部文件仍按各自规则管理。

### 壁纸选择保存

TF卡可用时，固定壁纸、轮播目录及上一张轮播图片记录保存在隐藏目录`.readpico/settings`的两个校验副本中；保存会同步并读回确认，不依赖内部NVS可写空间。旧NVS壁纸设置仍可读取，设置的“保存与恢复”继续包含壁纸选择。图片本身保留在原目录；备份整张卡时请一并保留`.readpico`。

### 设置保存与电源失败

系统偏好只有在写入并独立读回确认后才应用。保存失败会保留本次开机中上次确认的值，并提示重试；读回失败表示结果未确认，不能据此断言数据未写入。读取失败不会被当作空配置继续覆盖，配置备份也会拒绝不完整快照。不会为修复设置自动擦除NVS。

锁屏和关机先检查当前页面的进度/草稿保存。失败时仍可锁屏浅睡并保留内存数据，暂缓深睡；主动关机/重启提供重试、仍然执行与取消，确认继续可能丢失尚未保存的数据。关机或重启交接失败会返回可操作原页，避免因提前卸载TF而丢失当前阅读资源。现有“先浅后深”和“彻底关机”选项保持不变。
