# if-ink OS 0.2.3 Beta 2

修正 Beta 1 的横屏转向颠倒。横屏阅读会在后台检查持握方向，方向稳定后自动转向。平放、触控和拖动时保持当前方向。

已安装 if-ink OS 的 Pico 可进入「设置 → 固件信息 → 在线升级 → Beta」，也可以使用 TF 升级包。本公开 Beta 的终端模式未编入固件。

Fixed inverted landscape orientation in Beta 1. Landscape reading now follows the device once its orientation stabilizes, while preserving orientation during touch and when flat.
