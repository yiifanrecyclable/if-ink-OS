04 / DESK TO DEVICE

整理在这里。
阅读在那里。

坚果云负责连接，TF 卡负责留下。
下载以后，离线也能继续阅读。

Obsidian 整理 Markdown 文本→坚果云 收件文件夹→Pico 选择下载 · 离线阅读
A.

坚果云，按需取回文件

在“设置 → 坚果云同步”填写账号、第三方应用密码和已存在的收件文件夹，例如 PicoBox。主账户密码不能代替应用密码。

打开“文件 → 坚果云同步”，查看列表，再选择 MD、TXT、EPUB、PNG/JPG/JPEG 图片或 TTF 字体下载到 TF 卡，自动存入 markdown、books、pictures、fonts。图片上限 2 MiB，字体上限 64 MiB。它是按需下载流程，适合先选好再读。

B.

Obsidian，一条更顺手的路

搭配独立项目 Sent to E-ink Reader，将 Markdown 文本推送到坚果云收件目录，再在 Pico 上下载。插件与固件分别安装，固件包不包含插件。

当前版本推送纯文本，图片与笔记嵌入转为文字说明。修改笔记后需再次手动推送，同名文件会覆盖更新；Pico 上也需重新选择下载。

也可以直接传。

“文件”页提供 WiFi / 热点、坚果云同步与 USB 连接。用 USB 读卡或读卡器复制文件时，先安全断开，再回设备打开内容。

01 / BANNER

一张图，一句文字，一个今天。

长按首页 Banner，或进入“设置 → 显示与个性化 → 首页Banner”。背景、日期、文字是三个独立图层，可分别启用与调整。文字最多四行，支持字体、字号、对齐和上下位置；预览满意后点“保存”统一生效，取消或离开会放弃草稿。

背景可选 PNG / JPG / JPEG，单张不超过 2 MiB，按原比例居中铺满并裁切。推荐按 684 × 300 准备，默认从 TF 卡 banner pic 文件夹选图。0.1.4 起已内置“思考大猩猩”，卡就绪时自动释放为可选文件，不会自动应用，也不覆盖已有同名文件。

02 / READING HISTORY

把“最近读过”，延伸为“读过的日子”。

点击首页“阅读打卡”右侧的“更多”，或长按整个打卡区域，按日查看阅读时长。通过“目标设定”选择每日30至180分钟，默认90分钟；热力图最深色和详情横条满格共用目标，达标格内显示圆头灰色对勾。没有阅读的日期也会列出，实际时长以分钟显示。

长期记录存放在 .readpico/reading，不按固定天数淘汰，容量取决于 TF 卡。旧系统尚保留的近期记录会迁入；已经被覆盖的旧日期无法补回。请保持设备日期可靠，并单独复制这个文件夹备份完整历史。

03 / LOCK SCREEN

07 / INSTALL & UPDATE

从这里，
开始新的阅读日常。

当前版本 0.1.7
先确认机型：Pico RDP-G01-W。

首次安装

电脑在线刷机

从原系统迁移，选这一条。
不需要 Python 或刷机工具。

首次安装会重写分区表，请先备份重要数据。原系统的本地升级不接受 IF 镜像。

  1. 01
    用电脑端 Chrome 或 Edge 打开本页。
  2. 02
    唤醒 Pico，用可传数据的 USB 线连接电脑。退出 USB 读卡模式，关闭其他占用串口的程序。
  3. 03
    点击下方“连接 Pico，安装固件”，选择设备对应串口，再按弹窗确认安装。
  4. 04
    保持连接，等待写入、校验与重启。在“设置 → 固件信息”核对版本 0.1.7。

正在加载在线安装按钮…

只有点击连接按钮后才会请求串口。使用 ESP Web Tools，安装器不执行整片擦除，不要额外添加擦除命令。

已有 IF / if-ink OS

TF 卡本地升级

无需重新在线刷机。
同版本无需重复安装。

  1. 01
    可先在“设置 → 保存与恢复”备份配置，再下载 TF 卡升级包。完整关机后取卡。
  2. 02
    解压，将 Pico-IF-update.bin 复制到 TF 卡根目录，替换旧同名更新文件。安全弹出，插回设备。内置大猩猩底图会在升级后卡就绪时自动释放，无需手动复制图片。
  3. 03
    开机，进入“设置 → 固件信息 → 本地升级”，核对 0.1.7 并确认。旧 IF 系统的入口为“系统升级”。

保持充足电量或 USB 供电。此路径只写应用槽，不改分区，书籍、文档与设置继续使用。

之后的版本，设备上检查。

系统界面支持中文与 English，可在“设置 → 系统与设备 → 系统语言”切换。本版包含独立在线更新器，可在“设置 → 固件信息 → 在线升级”检查并确认后续更新。旧版若没有此入口，先通过 TF 卡升到本版。GitHub 连接受网络环境影响，连接困难时可用 TF 卡升级。

备用方式：手动 USB 安装 ＋

下载离线 USB 刷机包，预先准备 Python 3 与 esptool 5.4.0。安装工具需联网，写入使用本地文件。在解压包目录打开终端，把 PORT 换成实际串口：Mac 常见 /dev/cu.usbmodem…，Windows 为 COM…。

python3 -m pip install esptool==5.4.0
python3 -m esptool --chip esp32s3 --port PORT --baud 460800 --before default-reset --after hard-reset write-flash @flash_args

Windows 将 python3 换成 py；PowerShell 请把 '@flash_args' 加引号。连接不稳定可改为 --baud 115200。保持目录结构，不格式化 TF 卡，不擦除整片 Flash。本机型没有 BOOT / RESET 物理按键。

10 / BEFORE YOU ASK

一些会遇到的问题。

我的设备可以安装吗？＋

仅适用 Pico RDP-G01-W（ESP32-S3，16 MB Flash）。不要用于其他机型。if-ink OS 是独立衍生固件，首次从原系统迁移，请使用本页在线安装或对应 USB 四段包。

为什么没有在线安装按钮，或找不到串口？＋

请用电脑端 Chrome / Edge 打开 HTTPS 页面。确认设备已唤醒、数据线支持传输，退出 USB 读卡模式并关闭串口监视器等程序。也可换数据线、拔插后重试；工具加载失败时刷新页面，或使用离线 USB 包。

升级后找不到原来的书籍或字体？＋

当前标准目录固定为 books、fonts、markdown。旧自定义目录与文件会保留，但不会自动迁移，请用读卡器或 USB 读卡整理到标准目录。资源包只合并内部文件夹，不复制“TF卡资源”外层目录。

坚果云连接时，该填哪种密码？＋

填写坚果云第三方应用密码，不是主账户密码；收件文件夹也需预先创建。设备通过文件页列出内容并按需下载。固件与插件发布包均不会预置你的账号。

Markdown 能直接读取任意网页或复杂表格吗？＋

文档阅读使用支持的 Markdown 子集。标准管道表格可换行与分页；HTML、嵌套或合并单元格表格不在支持范围。支持文档内的本地 PNG/JPEG 插图，需使用兼容附件路径；推荐用 Send to E-ink Reader 0.1.8 开启图片发送，默认 684×1216、16 灰阶。表内图片、远程图片和 HTML 图片不在支持范围。

配置备份能带走所有资料吗？＋

配置备份不复制书籍、文档、字体、图片和 TF 卡长期阅读归档。完整备份请另外复制卡内文件，包含隐藏目录 .readpico/reading。配置内含连接密码，不宜公开分享。

本页的展示能说明真机刷新与续航表现吗？＋

图片用于展示界面与功能，静态展示不能作为墨水屏刷新速度、残影、休眠或续航的测试依据。0.1.7 已完成构建与宿主检查，新增功能的最终显示及休眠效果仍需实体设备验证。
