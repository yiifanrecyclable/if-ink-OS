if-ink OS v0.1.3

支持 Markdown 文档的 Pico 固件。仅适用 Pico RDP-G01-W。

EPUB / TXT / Markdown 阅读、坚果云同步、表格显示、自定义 Banner、长期阅读记录、壁纸轮播与阅读控制面板。基于 Pico Reader rc83，选择性采用后续 rc88 / rc95 的阅读、刷新与存储改进。

版本页面 · 对应源码与构建说明 · 源码 ZIP

首次安装：在线刷机

无需安装 Python 或刷机工具。首次从原系统迁移会重写分区表，请先备份重要数据。

  1. 使用电脑 Chrome 或 Edge 打开本页。
  2. 唤醒 Pico，通过 USB 数据线连接电脑，退出 USB 读卡模式并关闭其他占用串口的程序。
  3. 点击连接按钮，选择 Pico 对应的串口，按提示确认安装。
  4. 保持连接，等待写入、校验和重启，在“设置 → 固件信息”核对版本 0.1.3。

正在加载在线安装按钮…

使用 ESP Web Tools。安装器不执行整片擦除；不要额外添加擦除命令。

已有 IF / if-ink OS：TF 卡升级

  1. 下载下方 TF 升级包，完整关机后取卡。
  2. 解压，将 Pico-IF-update.bin 和 banner pic 文件夹合并到 TF 卡根目录，替换旧同名更新文件，安全弹出并插回设备。
  3. 开机，进入“设置 → 固件信息 → 本地升级”，核对 0.1.3 后确认；旧 IF 系统中入口为“系统升级”。

保持充足电量或 USB 供电。升级只写应用槽，不改分区。原系统的本地升级不接受 IF 镜像，首次请在线安装。

手动 USB 安装（备用）

准备 Python 3 与 esptool 5.4.0，安装工具需联网。解压 USB 包，在包目录打开终端，将 PORT 换成实际串口（Mac 常见 /dev/cu.usbmodem…，Windows 为 COM…）。

python3 -m pip install esptool==5.4.0
python3 -m esptool --chip esp32s3 --port PORT --baud 460800 --before default-reset --after hard-reset write-flash @flash_args

Windows 将 python3 换成 py。连接不稳定改为 --baud 115200。保留目录结构，不要格式化 TF 卡或擦除整片 Flash。本机型没有 BOOT/RESET 物理按键。

应用镜像 SHA256：7a9d2991e9130ebf456bfabe8673a3773f5242997b7fb9d9ac50e33df7b0d53d
