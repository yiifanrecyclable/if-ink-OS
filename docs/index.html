正式版 0.2.6 · Pico RDP-G01-W

电脑在线安装

  1. 01在电脑端使用 Chrome 或 Edge 打开本页。
  2. 02唤醒 Pico，用可传数据的 USB 线连接电脑，并退出 USB 读卡模式。
  3. 03点击连接按钮，选择 Pico 对应的串口并确认安装。
  4. 04等待写入、校验与重启，在“设置 → 固件信息”确认版本。
