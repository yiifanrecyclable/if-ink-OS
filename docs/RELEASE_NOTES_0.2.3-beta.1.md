# if-ink OS 0.2.3 Beta 1

## 中文

本 Beta 重点改进阅读控制和刷新效果：图书横屏提供三种版式，控制面板和翻页热区随实体按键与持握方向调整；阅读状态栏排版更紧凑；横屏水波纹逐行扫描，含插图的翻页采用灰阶差分，以减少整屏闪烁。

书籍和 Markdown 正文字号上限提高至 100 px，字体列表改进名称展示和预览；系统列表支持实体左右键翻页。

本公开 Beta 未编译 InkBuddy/终端模式。固件已完成宿主回归，本次镜像尚未刷入硬件。

## English

This beta focuses on reader controls and refresh behavior. It includes three landscape reading layouts, orientation-aware controls and page-turn zones, improved reader status layout, and reduced full-screen flashing during landscape page turns.

Book and Markdown body text can now reach 100 px. Font lists improve name display and previews, and system lists support paging with the side keys.

InkBuddy/terminal mode is disabled in this public beta. Host regressions passed; this exact image has not been flashed to hardware.
