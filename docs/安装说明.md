# if-ink OS v0.2.0-beta.9 安装说明

仅适用 Pico RDP-G01-W（ESP32-S3、16 MB Flash）。本版基于 Pico Reader rc83，选择性采纳 rc88/rc95/rc97 底层改进。

本版以稳定性加固为主，发布 **if-ink OS 0.2.0 beta r9**。这是 Beta 测试版，尚未以宿主测试代替真机验收。

- 修复 r8 壁纸图片预览的左侧缺失、竖条纹与底部按钮显示异常：缓存改用旋转感知的逻辑像素坐标。
- 修复十分钟浅睡转深睡时的确定性崩溃：移除产品所用 Picolibc 不支持的 `fflush(NULL)`，保留写入方独立同步、卡状态检查及自动转深睡策略；交接失败仍保持锁屏。
- TXT/EPUB索引、元数据及封面统一按媒体会话/文件变更失效，避免同名、同大小、同修改时间替换后继续读旧缓存。**冷启动、重新接管TF或USB交接后的首次使用会重建缓存，可能较慢；本版没有实施书架加载性能优化。**
- 拼豆草稿 V2 保存最后一次成功导出的基线，兼容旧草稿。未导出草稿恢复后仍可保存，已导出且未修改的画布不重复导出。
- 设备与网页文件操作统一更新所有匹配的系统字体、阅读字体与固定壁纸引用；写入失败明确提示，并保留可重试的引用待办。
- 带上 r7 后的壁纸浏览改进：固定/轮播共用图片浏览器、列表/缩略图、精准退出/上级触区；轮播可含子目录、禁止选择根目录。设置子页退出触区收窄；网页隐藏系统点目录。

**安装：** 已安装 if-ink OS：设置 → 固件信息 → 在线升级 → **Beta**；也可下载 TF 升级包，将其中 `Pico-IF-update.bin` 放卡根目录后执行本地升级。首次安装使用 USB 离线包。**稳定 Latest、稳定升级源和网页默认刷机保持 0.1.7。**

请先备份重要资料，保留TF隐藏目录 `.readpico/progress`、`.readpico/records`、`.readpico/settings`。不要为排查问题改名或移动 books、fonts、markdown、pictures、banner pic 等固定目录。本轮没有改变 r3 逐本进度格式、r7 NVS迁移规则或普通阅读触控/翻页策略。

**验证范围与已知限制：** 产品配置完整 ESP-IDF 构建及针对缓存/草稿/引用、触控、显示、Markdown、设置容量/失败重试、睡眠/电源和壁纸旋转的独立宿主回归已通过，对应源码包另做独立完整构建；摘要清单和构建证据随版本提供。旧汇总 `tools/run_book_management_tests.sh` **未通过，不计通过**：其旧 `book_ui_host_test.py` 抽取已移除的 `reader_margin_width`，存在测试脚本漂移。本版未宣称修复跨记录备份恢复中断（R4）或所有书籍元数据迁移的失败恢复；三项设置引用事务不等于所有关联记录的完整事务。物理掉电、残影、首用重建耗时仍需下面的真机验收。

## 真机验收（请在副本/专用测试资料上执行）

1. **缓存替换：** 先打开测试 TXT/EPUB 建立缓存；通过 USB 用同路径、同字节数、保留修改时间的另一份内容替换，安全退出 USB 后再打开，核对正文、章节、元数据与封面。冷重启后再核对，并记录首次书架/开书耗时；不要改固定目录名。
2. **拼豆未导出：** 新画几颗豆，不导出PNG，短按电源锁屏；拔掉USB，等待 **15分钟**，按键唤醒后回拼豆点击保存，应生成图片。再重启，未修改时应不能重复导出；编辑后应可再次保存。
3. **同源双字体引用：** 选择一份可正常读取的测试TTF，同时设为系统字体与阅读字体；分别使用设备文件管理和网页管理移动/改名它（移动文件，不改固定fonts目录），两项设置都应跟随。冷重启后复核；另用副本测试删除后回退。遇写入失败保留卡上待办并重试，不手动删除隐藏文件。
4. **r8壁纸旋转回归：** 设置 → 锁屏壁纸，打开一张非均匀图预览并使用；检查左边缘、整张图、底部按钮和锁屏画面，没有缺边或竖条纹；再测列表/缩略图、退出和上一级。
5. **r8十分钟交接回归：** 拔USB，从EPUB和Markdown阅读中分别锁屏超过15分钟。设备应保持锁屏、不自行回首页；按电源唤醒后回到原阅读上下文，进度保持。再做USB供电对照；若异常请导出 diagnostics/ifink-settings.csv 及其.previous（如有）。
6. **既有持久化回归：** 改系统/阅读字体、字号、页边距、关机策略和自动休眠时间，分别软重启、彻底关机后冷启动，设置应保留；书签、逐本进度、阅读打卡和最近阅读顺序应保持一致。
7. **恢复中断专测（进阶，勿用唯一资料）：** 专用卡先做备份→普通恢复，核对进度/书签/设置一致；若需验证R4，只在完整外部副本及可恢复设备上测试恢复中断→重启，确认恢复材料保留并可手动恢复。这项风险尚未消除，不以普通恢复成功替代断电验证。

基于 [kiikoread / Pico Reader](https://github.com/wegooo-cell/read-pico-reader)，感谢[原作者](https://wegooo-cell.github.io/read-pico-reader/)。if-ink OS 为独立衍生版本，保留原版权及组件许可。


## 首次安装：Beta 离线 USB 安装

本 Beta 使用下方离线 USB 包安装。在线刷机页默认仍提供稳定版0.1.7；请勿把稳定版按钮误认为Beta安装。首次从原系统迁移会重写分区表，请先备份重要数据。安装器不执行整片擦除；不要额外添加擦除命令。

## 已有 IF / if-ink OS：TF 卡升级

1. 可先用“设置 → 保存与恢复”备份配置。完整关机后取卡，用读卡器接电脑。
2. 解压 TF 升级包，将 `Pico-IF-update.bin` 放入卡根目录，替换旧同名更新文件。
3. 安全弹出，插回 Pico 后开机；进入“设置 → 固件信息 → 本地升级”，核对 0.2.0-beta.9 后按提示安装。旧 IF 界面中的入口为“系统升级”。
4. 保持充足电量或 USB 供电，等待自动重启。升级只写应用槽，书籍、文档与设置继续使用。

保留 `Pico-IF-update.bin` 文件名是为了兼容旧 IF 设备。升级包不含分区表或 bootloader。

## 手动 USB 刷写（离线固件包）

USB 包包含同一次构建的四段固件及 `flash_args`。刷机前需在电脑准备 Python 3 和 esptool 5.4.0；工具安装需要网络，固件写入使用本地文件。

Mac 安装工具：`python3 -m pip install esptool==5.4.0`；Windows 将 `python3` 换成 `py`。遇到 Python 环境限制时使用虚拟环境。

在解压后的 USB 包目录打开终端，把 PORT 换成实际串口名（Mac 通常 `/dev/cu.usbmodem…`，Windows 为 `COM…`）：

```sh
python3 -m esptool --chip esp32s3 --port PORT --baud 460800 --before default-reset --after hard-reset write-flash @flash_args
```

连接不稳定可改为 `--baud 115200`。保持目录结构，等待四段写入和校验完成。勿添加 erase-flash，勿格式化 TF 卡。本机型没有 BOOT/RESET 物理按键。

写入位置：0x0 引导器、0x8000 分区表、0x10000 应用、0xd10000 OTA 初始数据；dio / 80m / 16MB。设备在线升级及 TF 升级仅写应用；首次安装才使用 USB 四段包。

## 首次准备 TF 卡

解压资源包，把 `TF卡资源` 内的 `fonts`、`system` 合并到 TF 卡根目录。保留许可文件。已有字体/词库可保留；固件会在卡就绪时自动释放内置可选图片，无需手动复制。

- `banner pic/思考大猩猩.png`：固件内置的684×300可选底图，卡就绪时自动校验解压；不会自动设为背景，也不覆盖同名文件。缺卡时暂缓，之后插卡挂载成功会补充。
- `pictures/默认壁纸.png`：684×1216、16阶灰度，卡就绪时自动释放；未选自定义壁纸时作为默认锁屏，已有自选壁纸与同名文件不覆盖。
- `fonts/PicoSans-Medium.ttf`：标准中文字体，系统/阅读可选择。
- `system/ime/pinyin.ifdict`：离线拼音词库。
- 图书放 `books`，Markdown 放 `markdown`；不要把整个“TF卡资源”外层目录复制进去。旧 `font` 或自定义目录中的文件需自行移到标准目录，系统不会擅自搬动。

## 坚果云与后续更新

“设置 → 坚果云同步”填写账号、第三方应用密码和已存在的收件文件夹（如 PicoBox），通过应用页“坚果云同步”选择 MD/TXT/EPUB、PNG/JPG/JPEG图片或TTF字体下载，自动分别保存到markdown/books/pictures/fonts。图片≤2MiB、TTF≤64MiB；已选用的同名字体需先切换其他字体再覆盖更新。主账户密码不能代替应用密码。

Markdown图文：普通插图与文字纵向混排，长图整页等比显示；所有图片区域沿用固定阅读操作，不提供点击放大。附件在 `markdown/attachments`，坚果云下载正文时一并拉取。Obsidian社区插件名称为Send to E-ink Reader，0.1.10可开启本地图片发送，并识别后缀与实际编码不一致的附件，默认Pico参数为684×1216、16灰阶。插件图片发送默认关闭，需要用户自行开启；纯文本操作保留。

系统第三栏为应用：集中存储卡管理、WiFi/热点、USB、坚果云和数字拼豆。数字拼豆支持六阶灰度、32步撤回、清空、PNG保存及残局恢复；保存作品在pictures/pindou。在线更新新增稳定/测试双通道，本Beta通过测试通道发布，稳定版保持0.1.7；触控及OTA闪屏修复尚需Beta实机验证。

WiFi／热点双栏管理网页，可编辑Banner与锁屏、自动显示设备真实排版、选择电脑TTF并确认同步到fonts，右侧提供TF文件管理与分类上传。固定根目录标注用途并保护目录本身。设备Banner高度使用同行滑块，英文保存/取消等宽。首页最近阅读右侧取消类别小字，利用完整高度自适应最多六行，仅保留行间线；阅读面板英文底栏统一字号。修复唤醒按键重复触发和在线更新中途失败，增加断线恢复并减少进度刷新。

本版包含独立在线更新器：后续在“设置 → 固件信息 → 在线升级”检查并确认安装。旧版本如无该功能，先用 TF 升级到本版。GitHub 连接受网络环境影响，可改用 TF 升级。在线更新没有在本次制作中执行真机安装；模拟器不执行刷写。

配置备份含连接密码，请妥善保管。公开包不含账号配置、用户图书或测试日志。应用 SHA256：`a31b8bf7596e161b94a48443630531c77300f6ed6f93cac50071c2fc51044247`。

包内 `SHA256SUMS` 可在 Mac 执行 `shasum -a 256 -c SHA256SUMS` 校验。来源和源码见 NOTICE.txt，重新编译与替换 epdiy 说明见对应版本 BUILDING.md。
