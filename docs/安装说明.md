# if-ink OS v0.1.2 安装说明

仅适用 Pico RDP-G01-W（ESP32-S3、16 MB Flash）。本版基于 Pico Reader rc83，选择性采纳 rc88/rc95 底层改进。

## 首次安装：在线刷机（推荐）

1. 电脑 Chrome 或 Edge 打开 https://yiifanrecyclable.github.io/if-ink-OS/ 。
2. 唤醒 Pico，用可传数据的 USB-C 线连接电脑，退出 USB 读卡模式，关闭占用串口的程序。
3. 点击“连接 Pico，安装固件”，选择插入设备后新增的串口，确认后等待安装、校验和重启。
4. 在“设置 → 固件信息”核对版本 0.1.2。

在线安装无需 Python。首次从原系统迁移会重写分区表，请先备份重要数据。本安装器不执行整片擦除，不要额外添加擦除命令。原系统的本地升级不接受 IF 镜像。

## 已有 IF / if-ink OS：TF 卡升级

1. 可先用“设置 → 保存与恢复”备份配置。完整关机后取卡，用读卡器接电脑。
2. 解压 TF 升级包，将 `Pico-IF-update.bin` 放入卡根目录，替换旧同名更新文件。
3. 安全弹出，插回 Pico 后开机；进入“设置 → 固件信息 → 本地升级”，核对 0.1.2 后按提示安装。旧 IF 界面中的入口为“系统升级”。
4. 保持充足电量或 USB 供电，等待自动重启。升级只写应用槽，书籍、文档与设置继续使用。

保留 `Pico-IF-update.bin` 文件名是为了兼容旧 IF 设备。升级包不含分区表或 bootloader。

## 手动 USB 刷写（离线固件包）

USB 包包含同一次构建的四段固件及 `flash_args`。刷机前需在电脑准备 Python 3 和 esptool 5.4.0；工具安装需要网络，固件写入使用本地文件。

Mac 安装工具：`python3 -m pip install esptool==5.4.0`；Windows 将 `python3` 换成 `py`。遇到 Python 环境限制时使用虚拟环境。

在解压后的 USB 包目录打开终端，把 PORT 换成实际串口名（Mac 通常 `/dev/cu.usbmodem…`，Windows 为 `COM…`）：

```sh
python3 -m esptool --chip esp32s3 --port PORT --baud 460800 --before default-reset --after hard-reset write-flash @flash_args
```

连接不稳定可改为 `--baud 115200`。保持目录结构，等待四段写入和校验完成。勿添加 erase-flash，勿格式化 TF 卡。本机型没有 BOOT/RESET 物理按键。

写入位置：0x0 引导器、0x8000 分区表、0x10000 应用、0xd10000 OTA 初始数据；dio / 80m / 16MB。设备在线升级及 TF 升级仅写应用；首次安装才使用 USB 四段包。

## 首次准备 TF 卡

解压资源包，把 `TF卡资源` 内的 `fonts`、`system` 合并到 TF 卡根目录。保留许可文件。已有这些资源无需重装。

- `fonts/PicoSans-Medium.ttf`：标准中文字体，系统/阅读可选择。
- `system/ime/pinyin.ifdict`：离线拼音词库。
- 图书放 `books`，Markdown 放 `markdown`；不要把整个“TF卡资源”外层目录复制进去。旧 `font` 或自定义目录中的文件需自行移到标准目录，系统不会擅自搬动。

## 坚果云与后续更新

“设置 → 坚果云同步”填写账号、第三方应用密码和已存在的收件文件夹（如 PicoBox），通过文件页“坚果云同步”选择 MD/TXT/EPUB 下载，内容页离线阅读。主账户密码不能代替应用密码。

本版包含独立在线更新器：后续在“设置 → 固件信息 → 在线升级”检查并确认安装。旧版本如无该功能，先用 TF 升级到本版。GitHub 连接受网络环境影响，可改用 TF 升级。在线更新没有在本次制作中执行真机安装；模拟器不执行刷写。

配置备份含连接密码，请妥善保管。公开包不含账号配置、用户图书或测试日志。应用 SHA256：`861a597b21797bdb5f52f722d45dd0f0be565bb0b31ee03a07c4dcd115a966dd`。

包内 `SHA256SUMS` 可在 Mac 执行 `shasum -a 256 -c SHA256SUMS` 校验。来源和源码见 NOTICE.txt，重新编译与替换 epdiy 说明见对应版本 BUILDING.md。
