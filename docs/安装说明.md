# if-ink OS 0.2.6 安装说明

仅适用 Pico RDP-G01-W（ESP32-S3、16 MB Flash）。首次安装前请备份重要数据。

## 首次安装

用电脑端 Chrome 或 Edge 打开[在线安装页](https://ifink.revcloud.top/install/)。唤醒 Pico，用可传数据的 USB 线连接电脑，退出 USB 读卡模式并关掉占用串口的程序。点击连接按钮后选择串口，确认安装，等设备重启后在「设置 → 固件信息」核对 0.2.6。

手动离线安装可使用同一正式版的 USB 四段包。解压后按包内说明和 `flash_args` 刷写，保留包内目录结构。首次安装会重新写入分区表，请勿执行整片擦除。

## 已安装 if-ink OS

进入「设置 → 固件信息 → 在线升级 → 稳定版」，核对版本后确认。TF 卡安装请解压 TF 升级包，把 `Pico-IF-update.bin` 放在卡根目录，再使用「本地升级」。

请保留 `books`、`fonts`、`markdown`、`pictures`、`banner pic` 和 `.readpico` 原有目录。配置备份可能含连接密码，请妥善保管。

此安装页使用正式版 0.2.6。应用镜像 SHA-256 为 `8f237870005ad429df50987f471d1fbab921d2564c3193db6cb613b15b35d1e6`。安装包和构建说明见[正式版 Release](https://github.com/yiifanrecyclable/if-ink-OS/releases/tag/v0.2.6)。
