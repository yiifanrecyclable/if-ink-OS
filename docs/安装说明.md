# if-ink OS 0.2.1 beta

适用于 Pico RDP-G01-W（ESP32-S3，16 MB Flash）。

- 深睡后按电源键唤醒时，设备会在已恢复的壁纸中央显示「启动中」，随后进入原页面。
- TF 卡就绪时跳过首页重复扫描。坚果云同步文档后保留书架封面，新增或更新图书时复用未变化的封面。
- 修复阅读中定期全刷后顶部标题字号变化。

已安装 if-ink OS 的设备可从「设置 → 固件信息 → 在线升级 → Beta」安装，版本号为 `0.2.1-beta.1`。也可解压 TF 升级包，将 `Pico-IF-update.bin` 放入 TF 卡根目录，从「本地升级」安装。首次刷入 Beta 使用对应的离线 USB 包。官网默认刷机和稳定通道仍提供 0.2.0。

测试阶段分别在真机核对了阅读标题、同步后封面复用和深睡提示。发布镜像使用常规的 10 分钟转深睡设置，关闭测试提示音和自动性能日志。正式 Beta 镜像通过构建和宿主回归，未另做真机刷写。

基于 [Pico Reader / kiikoread](https://github.com/wegooo-cell/read-pico-reader)，感谢[原作者](https://wegooo-cell.github.io/read-pico-reader/)。源码和许可证随发布提供。

## 手动 USB 刷写（离线固件包）

USB 包包含同一次构建的四段固件及 `flash_args`。刷机前需在电脑准备 Python 3 和 esptool 5.4.0；工具安装需要网络，固件写入使用本地文件。

Mac 安装工具：`python3 -m pip install esptool==5.4.0`；Windows 将 `python3` 换成 `py`。遇到 Python 环境限制时使用虚拟环境。

在解压后的 USB 包目录打开终端，把 PORT 换成实际串口名（Mac 通常 `/dev/cu.usbmodem…`，Windows 为 `COM…`）：

```sh
python3 -m esptool --chip esp32s3 --port PORT --baud 460800 --before default-reset --after hard-reset write-flash @flash_args
```

连接不稳定可改为 `--baud 115200`。保持目录结构，等待四段写入和校验完成。勿添加 erase-flash，勿格式化 TF 卡。本机型没有 BOOT/RESET 物理按键。

写入位置：0x0 引导器、0x8000 分区表、0x10000 应用、0xd10000 OTA 初始数据；dio / 80m / 16MB。设备在线升级及 TF 升级仅写应用；首次安装才使用 USB 四段包。

## 首次准备 TF 卡

解压资源包，把 `TF卡资源` 内的 `fonts`、`system` 合并到 TF 卡根目录。保留许可文件。已有字体/词库可保留；固件会在卡就绪时自动释放内置可选图片，无需手动复制。

- `banner pic/思考大猩猩.png`：固件内置的684×300可选底图，卡就绪时自动校验解压；不会自动设为背景，也不覆盖同名文件。缺卡时暂缓，之后插卡挂载成功会补充。
- `pictures/默认壁纸.png`：684×1216、16阶灰度，卡就绪时自动释放；未选自定义壁纸时作为默认锁屏，已有自选壁纸与同名文件不覆盖。
- `fonts/PicoSans-Medium.ttf`：标准中文字体，系统/阅读可选择。
- `system/ime/pinyin.ifdict`：离线拼音词库。
- 图书放 `books`，Markdown 放 `markdown`；不要把整个“TF卡资源”外层目录复制进去。旧 `font` 或自定义目录中的文件需自行移到标准目录，系统不会擅自搬动。
