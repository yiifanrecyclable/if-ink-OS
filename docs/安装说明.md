# if-ink OS v0.2.0 安装说明

仅适用 Pico RDP-G01-W（ESP32-S3、16MB Flash）。本正式版以经过实机测试的r9t7为基线，不包含r9t8测量改动。

## 已安装if-ink OS

设置 → 固件信息 → 在线升级 → 稳定版，核对0.2.0后安装。也可解压TF升级包，把Pico-IF-update.bin放TF根目录，设置→固件信息→本地升级。

## 首次安装

电脑Chrome/Edge打开 https://yiifanrecyclable.github.io/if-ink-OS/ ，连接数据线后点击在线安装。在线刷机不需Python。手动离线USB包含同一次构建的bootloader、分区表、应用和OTA初始化数据；按包中flash_args使用esptool刷入，仅用于该机型，不执行整片擦除。

## 本版内容

- 应用页、数字拼豆、壁纸选择/轮播与文件操作卡片。
- 设置持久化、阅读时长/进度和最近阅读排序修复，以及媒体/文件引用、草稿和电源交接加固。
- 书架按需扫描文档，补封面仅重绘对应格；首页复用未变化的Banner。
- 封面持久缓存：首次显示时生成，重启后核验当前实际封面内容再复用，省重复解码。常规默认封面可复用；依赖外部字形的模板保守重建。仍保留原阅读水波纹及书架逐图输出。

请保留books、fonts、markdown、pictures、banner pic固定目录及.readpico隐藏数据；升级前可备份TF和配置，不要为排查改名固定目录。原书和进度不随封面缓存清理；本版未新增缓存孤儿GC。

本版已完成产品配置编译、相关宿主回归，以及r7/t3/t4/t6/t7阶段实机测试。缓存读取实机13/13命中；首次生成仍有开销。尚未消除所有极端掉电/跨记录恢复中断风险，宿主故障注入不替代真机长期使用。旧run_book_management_tests.sh汇总含历史脚本漂移，不计为通过；发布证据列明实际检查。

主体基于kiikoread/Pico Reader。原作者主页 https://wegooo-cell.github.io/read-pico-reader/ ，源码 https://github.com/wegooo-cell/read-pico-reader 。本项目为独立衍生版本，许可见NOTICE与LICENSE。
